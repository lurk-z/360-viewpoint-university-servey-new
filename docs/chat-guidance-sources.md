# ขอบเขตข้อมูลสำหรับแชทแนะแนว

ตรวจข้อมูลวันที่ 9 กันยายน 2569 การแนะนำใช้คณะ/หลักสูตร/แท็กอาชีพที่เผยแพร่จาก Admin และเชื่อมด้วย ID จริง ไม่มีการสร้างหลักสูตรจากชื่อหน้าเว็บหรือจาก Gemini

| แหล่งทางการที่ผู้ใช้ให้ | การใช้และข้อจำกัด |
| --- | --- |
| [งานหอพัก](https://dorm-pcb.kmutnb.ac.th/index), [แกลเลอรี](https://dorm-pcb.kmutnb.ac.th/gallery) | แยกหอชาย หอหญิง 1 ห้องพัดลม และหอหญิง 2 ห้องปรับอากาศ เมนูพาทัวร์เลือกอาคารก่อน; ค่าห้อง ห้องว่าง และการจองต้องตรวจประกาศล่าสุด |
| [หลักสูตร BAS](https://www.bas.kmutnb.ac.th/เกยวกบคณะ/ขอมลหลกสตร) | แยกหลักสูตร 4 ปี เทียบโอน และปริญญาโทตามวุฒิ ไม่ถือว่าชื่อสาขาเดียวกันหมายถึงเส้นทางรับเข้าเดียวกัน |
| [คณะอุตสาหกรรมเกษตรดิจิทัล](https://www.kmutnb.ac.th/faculty-and-agencies/prachin-campus/คณะอตสาหกรรมและการเกษตร.aspx), [เว็บไซต์คณะ](https://agro.kmutnb.ac.th/) | ใช้ชื่อคณะปัจจุบันและกลุ่มอาหาร โภชนาการ ผลิตภัณฑ์/เกษตร; ลิงก์มหาวิทยาลัยนี้เป็นคณะเกษตร ไม่ใช่ FITM |
| [FITM](https://www.fitm.kmutnb.ac.th/) | จับชื่อ FITM และชื่อไทยกับคณะเทคโนโลยีและการจัดการอุตสาหกรรมที่เผยแพร่จริง |
| [InAE](https://iee.eng.kmutnb.ac.th/iee/inae-4-ปี/), [แนวทางอาชีพ InAE](https://www.admission.kmutnb.ac.th/sites/default/files/2023-03/01-inae.pdf) | เอกสารระบุปริญญาตรี 4 ปีที่ปราจีนบุรี แต่เทียบโอนที่กรุงเทพฯ จึงไม่เพิ่มสาขาหรือรูปแบบการเรียนจากหน้าแนะแนวรวมโดยอัตโนมัติ |
| [รับสมัครวิศวกรรมศาสตร์](https://www.eng.kmutnb.ac.th/admission), [แนวทางอาชีพมหาวิทยาลัย](https://www.admission.kmutnb.ac.th/career-guidance) | เป็นหน้ารวมหลายหลักสูตร/วิทยาเขต ต้องจับคู่กับ Program ID และ Faculty ID ที่เผยแพร่ก่อนเสนอคำแนะนำ |

บางหน้าหลักตอบช้าหรือดึงไม่ได้ในการตรวจครั้งนี้ ใช้หน้าคณะบนเว็บไซต์มหาวิทยาลัย แกลเลอรี และ PDF ที่เข้าถึงได้ร่วมกับข้อมูล Admin เดิม ไม่มีการอ้างว่าได้ซิงก์ข้อมูลสดจากทุกเว็บไซต์

ชื่อคณะและแนวทางอาชีพในคำตอบดึงจากข้อมูลที่เผยแพร่ ไม่รับชื่อคณะที่โมเดลสร้าง ไม่สัญญาการรับเข้า งาน รายได้ หรือใบประกอบวิชาชีพ และไม่แสดงลิงก์/ส่วนอ้างอิงท้ายคำตอบแชทตามการตั้งค่าของโครงการ

คำถามพาทัวร์ทั่วไป กิจกรรม คณะ หลักสูตร แนวทางอาชีพ และข้อมูลหอพักที่มีอยู่ตอบภายในระบบโดยไม่ใช้โควตา Gemini คำถามรายละเอียดอื่นยังใช้การตรวจเอกสารและ ID ฝั่ง Server
